| **快速建数据表** | `QuickTablePage.xaml` | 粘贴单表 INSERT，支持多条语句和批量 VALUES；提取字段并推断类型；编辑字段名/类型/长度/精度/可空属性，批量应用类型与长度；表名前缀保存、字段大小写调整、标识符引用与可选 DROP TABLE；生成并复制/导出四种数据库的建表 SQL | `InsertStatementParser` `QuickTableService` `SqlGeneratorService` `ImportSettingsService` |

## 主题系统说明

### 设计原则

- `LightTheme.xaml` / `DarkTheme.xaml` 提供颜色 **Token**（`SolidColorBrush`），`App.xaml` 默认加载浅色主题。
- 使用 `DynamicResource` 的控件随主题字典替换更新；当前部分页面和全局表格样式仍使用固定颜色，不能将主题切换视为全部界面均已适配深色。
- `App.xaml` 统一合并滚动条、轻提示、按钮、表格、输入框、卡片和公共样式资源。
- 共享表格样式以 `ModernDataGridStyle` 为基础；旧 `DataGrid*` 资源名作为兼容别名，快速建表另有专用派生样式。
- 各功能页按需要保留本地样式；系统设置当前未提供主题切换入口，切换能力由 `ThemeManager` API 提供。

### 主题切换方法

```csharp
// 切换到深色主题字典（固定颜色的控件不会自动适配）
ThemeManager.SwitchTheme("Dark");

// 切换回浅色主题
ThemeManager.SwitchTheme("Light");

// 获取当前主题
var current = ThemeManager.CurrentTheme; // "Light" 或 "Dark"
```

## 历史 Bug 修复记录

以下为原文保留的修复记录；本次仅更新文档，未修改程序代码。

| Bug | 原因 | 修复 |
|-----|------|------|
| CSV 对比：第二次选不同主键对比报错 | `BindCurrentPage` 中 `_currentPageRows.Clear()` 时 DataGrid 仍引用该列表，触发选择变化访问已清空数据 | 清空集合前，将汇总和明细表的 `ItemsSource` 置空 |
| 发票打印：勾选裁剪线但打印无效 | 原先仅预览绘制裁剪线，打印页未绘制 | `InvoicePrintService.BuildPrintPages` 接收 `showCutLine`，多张排版时绘制裁剪线 |
